# Business modules

`domain` contains pure lifecycle, expiry and counter policies plus typed audit payload schemas. `persistence` owns Mongoose schemas, named indexes, initialization and the transaction helper. Phase 2 verifies them against real MongoDB.

`jobs` now provides validated create/list/detail/ready/history endpoints through thin routes and a transaction-owning service. `history/append-event.ts` allocates sequences and appends events inside the caller transaction. `riders` now provides validated configuration/workload APIs with protected updates; shared transport contracts live under http and shared attempt/event DTOs under history. `recommendations` adds a pure eligibility/scoring engine and transactional evaluation/audit service. `dispatch` now implements atomic assignment/reservation, override validation and durable receipt/failure-history boundaries. `dispatch/resolution` and the release helper now implement guarded responses/expiry, while `worker` owns bounded persisted scanning and scheduler lifecycle. Next features add manual summaries, delivery/cancellation and dashboard services; ranking and domain policies stay independently testable. See docs/architecture.md for validation boundaries: document hooks do not replace guarded query updates or cross-document transactions.
